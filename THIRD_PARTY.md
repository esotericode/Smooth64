`vendor/manifest.json` records SHA-256 for every vendored libsm64 file. Run `python3 tools/check_vendor.py` to detect accidental edits. No action source was shortened into a hand-tuned approximation.

The public decomp's animation C files contain more than movement needs. The importer discards all skeletal rotation tracks and keeps the five timing/flag fields and first three translation channels. These values control action transitions and root motion; they are not a model/animation renderer. `web/animations.js` is generated by `tools/export_animations.py` from two files already in this repository — the vendored `mario_animation_ids.h` names and the loop ranges in `core/kinematics.inc.h` — so the frontend can tell which animation the core chose and how far through it the current frame sits. The poses drawn for each one are original work in `web/pose.js` and `web/poses.js`. No ROM, model, texture, audio, Nintendo level geometry, or full skeletal pose files are included.

`tools/build_sounds.py` records the exact source files, windows and SHA-256 checksums, and rebuilds the sprite from them. CC0 needs no attribution; Kenney is credited here as thanks. The slide scrape and lava crackle are generated at runtime by `web/audio.js`. No Nintendo audio is used: the movement core reports only the original sound *IDs* its actions request, and the game chooses its own samples for them.
