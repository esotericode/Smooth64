# Smooth64 — Game polish

A cleaner game experience, with the same rules everywhere.

## Play

Download **Smooth64-Browser.zip**, extract it, and open **Smooth64-Play.html**.
Or download the HTML file directly. Both work offline, with no setup or ROM.

## What's new

- A clean default HUD shows power and collectibles. The pause menu holds objectives, checkpoints, world selection, controls, and settings.
- Technical readouts and testing controls are behind **Menu → Settings → Developer tools**, off by default. Movement hints and the on-screen timer have their own saved settings.
- Cinder Caldera and the playground share coins, healing, lava damage, checkpoint beacons, collection effects, and recovery rules.
- The playground now has **34 healing coins across eleven destinations**, including a connected **Lava crossing** practice area. All original courses remain available.
- Each world's collectibles and checkpoints survive switching worlds and retries. Starting one world over leaves the other world's progress intact. Reloading starts fresh runs.
- Ledge transitions keep gloves planted, and running/decelerating feet stay above the floor as the body moves.
- Menus clear queued movement, gamepad Start opens the menu, touch cancellation releases controls, and collecting a star immediately pauses the game.

The full Cinder Caldera adventure is included: two stars, eight Ember Shards, and five checkpoint beacons.

## Verification

All 14 native and 44 Node tests pass, including 7,452 native/WASM state comparisons and traversal checks for the level and new lava practice route. Desktop, touch, settings, world switching, and offline browser checks pass in Chromium with no JavaScript or WebGL errors. The movement core and WASM are unchanged from v0.3.0.
